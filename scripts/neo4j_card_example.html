Neo4j

Native Graph Database · Labeled Property Graph Model

Нативная графовая СУБД, реализующая модель размеченного графа свойств. Данные хранятся в виде узлов, связей и свойств, что обеспечивает эффективное выполнение запросов по связям без JOIN-операций.

Модель данных
◉ Nodes — сущности предметной области. Могут иметь метки для категоризации: (:Person:Actor)
→ Relationships — направленные, типизированные связи: -[:ACTED_IN]->
{ } Properties — пары ключ-значение на узлах и связях: {name: 'Tom Hanks', born: 1956} 
MATCH (p:Person)-[:ACTED_IN]->(m:Movie)
WHERE m.title = 'The Matrix'
RETURN p.name, p.born
ORDER BY p.born
