# Микросервис-админка
```
url = localhost:8000
```
- Была создана на fastapi на скорую руку для быстрой вставки документов через localhost.
- ` Не безопасная, т. к. имеет доступ к backend/internal не вводя токен, и нет системы с логин/паролем.`
- Удобно для быстрого локального тестирования, `но не для прода`.
